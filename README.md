# Ai Rojgar - Interview Feedback Dashboard (React + Django)

Windows quick start (VS Code: File > Open Folder > this folder, then open Terminal):
    setup.bat      (first time only: installs Python + Node packages, creates database, loads demo data)
    run.bat        (starts backend :8000 and frontend :5173 and opens the browser)

Email: put your Gmail + Gmail App Password in backend\.env (EMAIL_HOST_USER, EMAIL_HOST_PASSWORD), save, run run.bat again.

Pages: Dashboard, Candidates, Evaluation, Compare, Settings (weights + domain skills).
Needs Python 3.10+ and Node.js 18+.
